\section{Adversarial Defenses and Deep Security Reinforcement Learning}
We formalize the automated protection of the multi-agent system (MAS) perimeter as a non-zero-sum Markov Game operating over an advanced windowed token filtering gateway.

\subsection{Reduced-Vocabulary Intrusion Detection Interface}
To protect the active multi-agent system from open-ended adversarial injection, the LLM user agents do not communicate directly with the symbolic call-stack. Instead, all input prompts are routed through a pre-built Intrusion Detection System (IDS). This gateway processes the incoming strings and projects them into a strictly \textit{reduced vocabulary form} before passing the tokens to the neuro-symbolic (NS) agents. This interface decoupling is maintained as a deliberate research boundary: because the current phase focuses on multi-agent consensus networks, the pre-built IDS acts as an isolated, upstream firewall layer.

\subsection{Google Windowed Perplexity Filter Gateway}
Within the reduced-vocabulary stream, the NS intrusion detection filter computes the maximum windowed per-token log-likelihood profile over a sliding token window $\mathcal{W}$ of size $k$ to isolate non-human-interpretable adversarial tokens:
\begin{equation}
\text{PPL}_{\text{max}} = \max_{i} \left[ \frac{1}{k} \sum_{j=i}^{i+k-1} \log P(\text{token}_j \mid \text{context}) \right]
\end{equation}
If $\text{PPL}_{\text{max}} < \tau$, where $\tau = -4.0000$ represents the security boundary threshold, an adversarial payload exception is triggered. The engine immediately refuses response execution, and grafts a text-notational Zanzibar relation tuple directly into the decision forest branch leaf nodes:
\begin{equation}

\end{equation}

\subsection{Symmetric Progression-Based DRL Game Mechanics}
The multi-agent system conditions defensive policy vectors by optimizing a fully observable defender reward function $r_1$ and a partially observable attacker reward function $r_2$. Let $\mathbb{I}$ represent the indicator function for active system state transitions. The structural rewards scale non-linearly over the attack progression matrix:
\begin{equation}
r_1(h_{ts}) = -\lambda_1 \cdot \mathbb{I}(\text{Exploit}) - \lambda_2 \cdot \mathbb{I}(\text{Impact}) - \lambda_3 \cdot \mathbb{I}(\text{Restore})
\end{equation}
\begin{equation}
r_2(h_{t2}) = \lambda_1 \cdot \mathbb{I}(\text{Exploit}) + \lambda_2 \cdot \mathbb{I}(\text{Impact})
\end{equation}
where $\lambda_1 = 2000$, $\lambda_2 = 1000$, and $\lambda_3 = 500$. The attacker's blind spot regarding the quality of service (QoS) degradation penalty $\lambda_3$ during a network \texttt{Restore} operation allows the defender's adaptive policy ($\pi_1$) to maintain dominance, minimizing long-term variance and securing the systemic performance space $V'$.
