## 🔍 How to Interrogate & Query the Decision Tree Model

You can actively query the frozen **Interlocking Forest Model** using high-level intensional feature vectors rather than raw strings by running the dedicated utility:

```bash
python3 query_job_situation.py
```

### 📊 Query Customization Template
Open `query_job_situation.py` to modify situational traits like `difficulty`, `effort`, and `reward`. Running the query loops forces the system to trace down your custom branch geometry and output the definitive terminal classification node, such as `['keeps_job']`.
