\begin{abstract}
AI data centers executing distributed training workloads impose periodic, spatially correlated active-power disturbances on transmission grids. We demonstrate that uncoordinated, synchronous software cycles act as a low-frequency periodic driving force that drives the grid into a period-doubling bifurcation cascade and localized blackouts. We present a decentralized Multi-Agent Reinforcement Learning (MARL) framework that discovers an emergent CSMA/CD protocol at the grid interface boundary, restoring global phase-locking and stability without centralized scheduling.
\end{abstract}

\section{Introduction and Problem Formulation}
Conventional energy management systems evaluate substations independently, failing to extract the cross-substation statistical structures that characterize synchronized load episodes. When high-performance deep learning clusters execute recurring batches (e.g., approximately 50 seconds per batch on DGX hardware), they generate localized active-power surges. To model this interaction, we append the aggregate data center load $P_{\text{AI}, i}(t)$ directly into the second-order Kuramoto swing equations for a grid node $i$:
\begin{equation}
m_i \ddot{\theta}_i + d_i \dot{\theta}_i = P_i - \sum_{j=1}^{N} K_{ij} \sin(\theta_i - \theta_j) - P_{\text{AI}, i}(t)
\end{equation}
where $m_i$ represents the rotational turbine inertia, $d_i$ represents the natural damping, and $K_{ij}$ defines the admittance coupling strength of the high-voltage transmission lines.

\section{Multi-Scale Control Models: Macroscopic Kuramoto and High-Fidelity EMT}
We implement a dual-resolution physical framework to model grid safety. Macroscopic stability is governed by the second-order Kuramoto swing matrices to isolate inter-area phase angle bifurcation cascades. Micro-level, sub-millisecond electromagnetic transient (EMT) numerical simulations are executed across a modified IEEE 39-bus New England testbed system using the open-source Julia package \texttt{PowerSimulationsDynamics.jl} to model non-linear inverter-based resource (IBR) Phase-Locked Loop (PLL) voltage tracking dynamics. 

When a data center drops high-amplitude periodic training steps on an IBR network, the low-frequency forcing signal interacts with high-speed internal current controller switching loops to induce severe \textit{control-loop interaction chaos}, forcing the local bus tracking voltage $V_i(t)$ to undergo catastrophic transient phase-slips and localized blackouts. These sub-millisecond variations are captured as extensional exemplars (\texttt{exs.pl}) sampled at a resolution of $\Delta t = 0.5\text{ ms}$:
\begin{equation}
\bm{\xi}_i(t) = \left[ V_i(t), \, \delta_i(t), \, P_{\text{IBR}, i}(t), \, Q_{\text{IBR}, i}(t) \right] \in \mathbb{R}^4
\end{equation}

\section{Throughput Derivation and Data Center Parameter Estimation}
Following the network routing principles of \textbf{Sherman \& Gable (1983)}, the emergent CSMA/CD protocol evaluates carrier availability using a normalized propagation delay parameter $a = \tau_{\text{prop}} / T_{\text{trans}}$. Given that electricity travels through copper busbars and high-voltage cabling at approximately $v = 0.67c \approx 2 \times 10^8\text{ m/s}$, a massive $1000\text{-meter}$ campus cable run maps to a propagation delay of $\tau_{\text{prop}} = 5\text{ }\mu\text{s}$. Bound against our sub-millisecond EMT control sample window of $T_{\text{trans}} = 500\text{ }\mu\text{s}$, the data center power network parameter is estimated exactly at $a = 0.01$. 

To anchor this optimization theoretically for reviewers unfamiliar with communication network benchmarks, the absolute throughput ($S$) as a function of offered traffic load ($G$) on a non-persistent CSMA/CD network channel is governed by the non-linear invariant:
\begin{equation}
S = \frac{G \cdot e^{-aG}}{G \cdot (1 + 2a) + e^{-aG} - (1 - e^{-aG})}
\end{equation}
When $a = 0.01$, the network realizes a highly efficient operational curve, enabling our decentralized MARL agents to maximize collective rewards and execute randomized delay gates before transient voltage drops breach perimeters. When conflicts emerge, agents initialize a preference-ordered dialogue game ($\text{Scounter} \succ \text{Sarg} \succ \text{Sconcede} \succ \text{Sclose}$) based on the algebraic principles of \textbf{Black, Hunter \& Pan} to safely align load profiles over narrow-band protocol channels.
