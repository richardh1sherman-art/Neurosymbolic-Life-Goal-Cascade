\section{Context Layer: Interlocking Decision Forests}

\subsection{Decision Trees as Associative Agent Memory}
Decision trees function as the agent's structural memory matrix and are used directly for context classification. The forest learns complex relational concepts as presented by sparse multi-modal exemplars. The non-terminal internal nodes are derived dynamically from the exemplars, evaluating testing features or structured parthood (\texttt{part\_of}) relationships. 

The decision tree recursion is explicitly configured to support nested conceptual compositionality, enabling the system to learn high-level meta-concepts strictly in terms of simpler, underlying local sub-concepts. Concepts are formulated in LISP S-expressions and can be indefinitely nested. Terminal leaf nodes retain partial exemplar arrays and domain-specific solution techniques. There are multiple independent trees trained for each category of concepts, ensuring that computationally analogous scenarios converge cleanly onto the exact same leaf node.

\subsection{\texttt{kb.pl} Logic as the Attention Guardrail}
The Prolog logic layer operates as an explainable attention filter. If a decision tree attempts to shift its focus or generate a new, random feature split to minimize statistical error over noisy data, the \texttt{kb.pl} file audits that choice. It blocks the tree from chasing noise or hallucinating branches, verifying that variables are legally and structurally meaningful to the macro-institution.
